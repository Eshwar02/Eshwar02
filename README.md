### 🚀 Featured builds

<table>
<tr>
<td width="50%" valign="top">

**[code-grammerizer](https://github.com/Eshwar02/code-grammerizer)**

AI code review assistant with a real-time collaborative editor. Paste a snippet, file, or Git repo URL to get a multi-provider AI review (Codestral, gpt-oss/Cerebras, Groq fallback) plus static analysis (Pylint, Bandit, Radon), then a scored, actionable review with one-click **"Fix with AI."** Teams jump into a shared Monaco editor with live cursors and CRDT sync (Yjs) to fix issues together.

> ⚡ Benchmarked: **100% delivery at 600 concurrent WebSocket connections**, sub-6ms p95 latency under realistic typing load.

</td>
